# System Security Inspector

A beginner-friendly Windows security inspection tool built with Python.

## Objectives

- Collect basic system information.
- Inspect running processes.
- Identify listening network ports.
- Inspect Windows services.
- Generate JSON security reports.

## Principles

- Read-only inspection.
- Modular architecture.
- Automated testing.
- Clear documentation.

## Platform

Windows

## Language

Python
